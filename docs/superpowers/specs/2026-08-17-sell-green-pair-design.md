# 售出系统绿色配对约束（Sell Green Pair）设计规格

日期：2026-08-17
状态：已确认（用户批准设计方案）

## 目标

绿色（common）武器/防具不能单独售出：一笔售出必须**恰好包含 2 件绿色物品**。蓝/紫/橙稀有度售出行为完全不变（一次 1 件）。计价不变——每件按其稀有度价格入账，一对绿色共得 2× 绿价。

## 已确认的决策

1. **纯对交易**：绿色只能恰好 2 件成对卖；绿色不能与其他稀有度混在同一笔；蓝/紫/橙仍单件卖。
2. **每件各计价**：卖一对绿色得 2× 绿色价格（单价语义不变，只是交易粒度变大）。
3. **固定规则**：不加导演开关、不进规则配置。
4. **实现方式**：扩展现有 `sell_item` 动作为多选载荷（方案 A），不新增独立动作。

## 交易规则

| 一笔售出内容 | 结果 |
|---|---|
| 1 件蓝/紫/橙 | 成功（现状不变） |
| 1 件绿 | 拒绝："绿色物品需成对售出" |
| 2 件绿（武+武 / 甲+甲 / 武+甲均可） | 成功，得 2× 绿价 |
| 1 绿 + 1 非绿 | 拒绝："绿色物品不能与其他稀有度混合售出" |
| 2 件非绿 | 拒绝："非绿色物品一次只能售出 1 件" |
| 3 件及以上 | 拒绝（长度校验先失败） |

## 后端

### 载荷与签名（player_action_scheduler.rs:345-361）

- 调度器 `sell_item` 分支改读 `action_params.item_ids`（**新增** `item_ids: Option<Vec<String>>` 字段；`item_id` 字段保留——装备/使用/丢弃等其他动作仍用它）。
- `GameState::handle_sell_item_action(&mut self, player_id: &str, item_ids: &[String]) -> Result<ActionResults, String>`（player_common_actions.rs:1027）。
- 现有前置校验（Alive/Born/NotBound + `end_rest_mode_for_action`）保持不变。

### 校验链（任一失败 → Info 仅发卖家，零状态变更）

1. 时间窗：非夜间（现状不变）。
2. `item_ids.len()` ∈ {1, 2}，否则 Info "一次只能售出 1 件非绿色物品或 2 件绿色物品"。
3. 每件都在玩家背包中（已装备天然不在 inventory，沿用现状），否则 "物品不在背包中"。
4. 每件都是武器/防具，否则 "只有武器和防具可以售出"。
5. 每件稀有度都已配置售出价，否则 "该道具稀有度未开放售出"。
6. **配对约束**：
   - len=1 且该件为 common → "绿色物品需成对售出"
   - len=2 且任一件非 common → "绿色物品不能与其他稀有度混合售出"（涵盖 2 非绿、1 绿+1 非绿）

### 应用与消息

- 原子应用：一次遍历移除全部命中道具，`coins += 各件价格之和`；不逐件提交。
- 卖家消息（合并一条）：`你售出了 A、B，获得 X 货币`（X 为总和，`format_price`）。
- 导演消息（合并一条）：`玩家 {name} 售出了 A、B（绿类），获得 X 货币`；多件时稀有度取各件（绿色对恒为绿类）。data payload：`item_names` 数组 + 总 `price` + 售后 `coins`（导演侧含 player 与每件 rarity）。
- 两类稀有度混卖不可能出现（规则禁止），无需为导演消息设计多稀有度文案。

## 前端（SellItemDialog.vue）

- radio 单选改 **checkbox 多选**（`selected: ref<string[]>`）。
- 实时校验提示（列表下方一行灰字/警示）：
  - 仅勾 1 绿 → "绿色物品需成对售出，请再勾选 1 件绿色物品"
  - 勾选含绿且含非绿 → "绿色物品不能与其他稀有度混合售出"
  - 勾 ≥2 件且全非绿 → "非绿色物品一次只能售出 1 件"
- 确认按钮仅在校验通过时可用；`handleConfirm` 调 `store.sellItem(selected)`。
- store `sellItem(itemIds: string[])` → `sendPlayerAction('sell_item', { item_ids: itemIds })`（替换原 `item_id` 载荷）。
- 演员端售出按钮入口、日间限制逻辑不变。

## 错误处理汇总

| 场景 | 行为 |
|---|---|
| 单卖绿件（前端勾选或直接发请求） | 后端 Info 拒绝；前端按钮禁用+提示 |
| 绿 + 非绿混合 | 后端 Info 拒绝；前端提示 |
| 2 件非绿 | 后端 Info 拒绝；前端提示 |
| ≥3 件 | 长度校验拒绝 |
| 对中一件不在背包/非武器防具/无价格 | 对应现有 Info 拒绝，零状态变更 |
| 夜间售出 | 现状不变（Info 拒绝） |
